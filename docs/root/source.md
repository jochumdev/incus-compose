# Source

The source code and documentation for `incus-compose` both live in the main
repository on [GitHub](https://github.com/lxc/incus-compose), with documentation
located in the `docs/` directory.

We use LeafWiki to render this page and edit it on a local machine.

A LeafWiki deployment is described on [examples leafwiki](/examples/leafwiki).

As a developer you can use `just leafwiki` to run a local instance then open
http://127.0.0.1:8080.
